## 5 · Gotchas re-confirmed today
- GitHub Actions silently not triggering for a branch is real (`actions/runs?head_sha=` = 0) — merging `origin/main`
  into the branch re-triggers it. Never call a head green on "no pending checks".
- `journal_write` (tenet MCP) reported success while writing nothing, twice. Append by hand with the ledger's own key
  set (`ts`, `type`, `summary`, `refs`) and verify with `wc -l`.
- Backticks inside a double-quoted `git commit -m` are command substitution — three words were eaten from a commit
  message today. Use a heredoc file (`-F`).
- Codex reviews from a worktree cwd work; point them at the MAIN checkout and `origin/<branch>` refs. The sandbox
  cannot write `.git/FETCH_HEAD`, so Codex reads the already-fetched remote-tracking ref — fetch locally first.
- Handover times measured today: 981 / 649 / 972 / 724 s, all inside the gate's 1500 s deadline.
